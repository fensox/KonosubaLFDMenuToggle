A mod for KonoSuba: God's Blessing on this Wonderful World! Love For These Clothes of Desire! which toggles the bottom menu bar on and off. The menu bar is hideous and covers up the artwork. The menubar toggles with F10. If you wish to change this hotkey, edit the mod config file in the BepinEx\config folder that is created after running the game once with the mod installed. This is my first mod, so yay. It took the game devs defacing the KonoSuba artwork to make me learn Unity modding.
